# strategy01 売買ルール仕様

`tools/strategy01.py` が定義する売買戦略の仕様書。コードの構造ではなく、「いつ買い、いつ売り、いくら買うか」を記述する。

## 1. 戦略の概要

EMA のゴールデンクロスで買い、デッドクロス・損切り・利確のいずれかで売る、日足の順張り(トレンドフォロー)戦略。

- ボラティリティ(ATR)が極端に低い/高い局面ではエントリーを見送る
- 損切り幅と利確幅は ATR から決め、利確幅は損切り幅の 2 倍(リスクリワード 1:2)
- 1 回のトレードで失う金額が資金の約 2% になるように、損切り幅から株数を逆算する

## 2. 前提条件

| 項目 | 内容 |
| :--- | :--- |
| 対象銘柄 | トヨタ自動車(`7203.T`) |
| 足種 | 日足(配当・分割調整済みの株価) |
| 売買方向 | 買いのみ(空売りなし) |
| 初期資金 | 1,000,000 円 |
| 売買単位 | 100 株単位(100 株未満は発注しない) |
| 手数料・スリッページ | 0(暫定値。未考慮) |
| 同時保有 | 1 ポジションのみ(保有中の買い増しはしない) |

## 3. 使用する指標

| 指標 | 設定 | 用途 |
| :--- | :--- | :--- |
| 短期 EMA | 終値の 5 日 EMA | クロス判定 |
| 長期 EMA | 終値の 20 日 EMA | クロス判定 |
| ATR | 15 日 | ボラティリティフィルター、損切り幅・利確幅、株数の計算 |
| ATR 比率 | ATR ÷ 終値 × 100(%) | ボラティリティフィルター |

## 4. 売買ルール

以下では、シグナルが出た日を **N 日**、その翌営業日を **N+1 日** と書く。
判断は必ず N 日の終値が確定した後に行い、発注は N+1 日に行う(当日の終値を見て当日に売買することはない)。

### 4.1 エントリー(買い)

次の 3 条件を**すべて**満たしたとき、N+1 日の**始値**で買う。

| # | 条件 | 内容 |
| :--- | :--- | :--- |
| 1 | ゴールデンクロス | N 日の終値時点で、短期 EMA が長期 EMA を下から上に抜けた(N-1 日は 短期 ≦ 長期、N 日は 短期 > 長期) |
| 2 | ボラティリティ | N 日の ATR 比率が 1.5% 以上 5% 以下 |
| 3 | 売買期間 | 約定日(N+1 日)が 2016-06-25 〜 2030-12-31 の範囲内 |

- すでにポジションを保有している間に出た買いシグナルは無視する
- 買いシグナルと売りシグナル(デッドクロス)が同じ日に重なった場合は、どちらも実行しない

### 4.2 エグジット(売り)

保有中に次のいずれかが起きたら、全株を売る。分割での売却はしない。

| 種類 | 発動条件 | 約定価格 |
| :--- | :--- | :--- |
| デッドクロス | N 日の終値時点で、短期 EMA が長期 EMA を上から下に抜けた(N-1 日は 短期 ≧ 長期、N 日は 短期 < 長期) | N+1 日の始値 |
| 損切り | 終値が損切りラインを下回った(以下になった) | その日の終値 |
| 利確 | 終値が利確ラインを上回った(以上になった) | その日の終値 |

同じ日にデッドクロスによる売りと損切り/利確が重なった場合は、損切り/利確(終値での約定)が優先される。

### 4.3 損切りライン・利確ライン

エントリー時に 1 回だけ決め、保有中は動かさない(トレーリングストップではない)。

- 損切り幅(%) = N 日の ATR × 2 ÷ N 日の終値
- 利確幅(%) = N 日の ATR × 4 ÷ N 日の終値
- 損切りライン = エントリー日(N+1 日)の終値 ×(1 − 損切り幅)
- 利確ライン = エントリー日(N+1 日)の終値 ×(1 + 利確幅)

エントリー条件の ATR 比率(1.5%〜5%)から、取りうる幅は次の範囲に収まる。

| | 最小(ATR 比率 1.5%) | 最大(ATR 比率 5%) |
| :--- | :--- | :--- |
| 損切り幅 | 3% | 10% |
| 利確幅 | 6% | 20% |

損切り/利確の判定はエントリー日の翌営業日から始まる(エントリー当日には発動しない)。

### 4.4 ポジションサイズ(株数)

損切りにかかったときの損失が資金の 2% になるように、投入する金額を決める。

- 投入割合 = 2% ÷ 損切り幅(%)
- 投入金額 = 手元資金 × 投入割合
- 株数 = 投入金額 ÷ N+1 日の始値 を、100 株単位に切り捨て

損切り幅が 3%〜10% の範囲なので、投入割合は資金の約 67%(損切り幅 3% のとき)〜 20%(損切り幅 10% のとき)になる。ボラティリティが高いほど株数は少なくなる。
切り捨て後の株数が 100 株に満たない場合は、そのエントリーは見送る。

**計算例**(資金 1,000,000 円、N 日の終値 2,500 円、ATR 62.5 円、N+1 日の始値 2,500 円)

1. ATR 比率 = 62.5 ÷ 2,500 = 2.5% → フィルター通過
2. 損切り幅 = 62.5 × 2 ÷ 2,500 = 5%、利確幅 = 10%
3. 投入割合 = 2% ÷ 5% = 40% → 投入金額 400,000 円
4. 株数 = 400,000 ÷ 2,500 = 160 株 → 100 株に切り捨て
5. 実際のリスク = 100 株 × 2,500 円 × 5% = 12,500 円(資金の 1.25%)

このように、100 株単位への切り捨てがあるため、実際のリスクは 2% より小さくなることが多い。

## 5. 1 トレードの流れ

| 日 | 出来事 |
| :--- | :--- |
| N 日(引け後) | ゴールデンクロスと ATR 比率を確認。損切り幅・利確幅・投入割合を計算 |
| N+1 日(寄り付き) | 始値で買い |
| N+1 日(引け) | この日の終値を基準に、損切りライン・利確ラインが確定 |
| N+2 日以降(引け) | 終値が損切りライン以下、または利確ライン以上なら、その終値で売り |
| デッドクロス発生日の翌営業日(寄り付き) | 損切り/利確にかかっていなければ、始値で売り |

## 6. 注意点・現状の制限

バックテスト結果を読むときに知っておくべき、現在の実装上の性質。

- **損切り/利確の基準は約定価格ではなくエントリー日の終値**。エントリー日に始値から大きく動くと、買値から見た実際の損切り幅は想定(ATR の 2 倍相当)からずれ、1 トレードの損失は資金の 2% からずれる
- **損切り/利確は終値だけで判定し、終値で約定する**。日中に高値・安値がラインに触れても発動しない。また、終値がラインを大きく超えていた場合はその終値で約定するため、損失は損切り幅より大きく、利益は利確幅より大きくなりうる
- **手数料・スリッページは 0**。実運用の成績はバックテストより悪くなる
- **売買期間の開始日(2016-06-25)は固定値**。それより前のデータは指標の計算にのみ使われる
- データの最終日時点で保有中のポジションは、決済されないまま評価される
- エグジットのシグナルは現在デッドクロスの 1 つだけ。複数指定した場合は「すべて満たしたとき」に売る(AND 条件)実装になっており、`docs/spec.md` の「OR 条件」という記述とは異なる
